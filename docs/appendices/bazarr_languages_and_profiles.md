# [Bazarr](https://www.bazarr.media/) languages and profiles

The languages and profiles I personally used for **[Bazarr](https://www.bazarr.media/)**, as a French speaker (adapt them to your own needs):

1. Go to `Settings → Languages → Selection`:

	| Field | Value |
	| --- | --- |
	| Languages Filter | `French`, `English` |

	Save

2. In `Settings → Languages → Profiles`, click on "Add New Profile", then:

	| Field | Value |
	| --- | --- |
	| Name | `FR/EN` |
	| Tag | |

	Click on "Add language" two times:

	| Field | Value |
	| --- | --- |
	| ID | 1 |
	| Language | `French` |
	| Subtitle Type | `Normal or hearing-impaired` |
	| Search only when... | `Always` |

	| Field | Value |
	| --- | --- |
	| ID | 2 |
	| Language | `English` |
	| Subtitle Type | `Normal or hearing-impaired` |
	| Search only when... | `Always` |

	Then set "Cutoff" to `fr`

	Confirm

3. Then in "Default Language Profiles For Newly Added Shows" enable "Series" and "Movies", select `FR/EN` for both, and save

4. In `Series`/`Movies`, select every element, apply the `FR/EN` profile to them, and save (anime are listed in `Series` with the other series)
