# [Bazarr](https://www.bazarr.media/) providers

The providers I personally used for **[Bazarr](https://www.bazarr.media/)**, as a French speaker (adapt them to your own needs):

<br>

### OpenSubtitles.com

Free account required (better if you have a VIP account)

| Field | Value |
| --- | --- |
| Username | `<YOUR_OPENSUBTITLES_USERNAME>` |
| Password | `<YOUR_OPENSUBTITLES_PASSWORD>` |
| Use Hash | ✅ |
| Include subtitles generated by opensubtitles.com's AI translation service in search results | ✅ |
| Include subtitles machine translated by users in search results | ✅ |

<br>

### SubDL

Free account required (API key in your account settings)

| Field | Value |
| --- | --- |
| API key | `<YOUR_SUBDL_API_KEY>` |
| AI-translate missing languages | ❌ |
| Include AI-translated subtitles in search results | ✅ |
